# Версии приложения

Используем дату выпуска: `vГГГГ.ММ.ДД`. Повторные выпуски в тот же день получают `.1`, `.2` и далее. Уже существующий тег `v2026.09.04` сохраняется; следующий выпуск 4 сентября — `v2026.09.04.1`. Это календарная нумерация, не SemVer.

## Одно место для версии

[`app-version.js`](../app-version.js) содержит номер без `v` и состояние `stage`:

- `preview` — изменения готовятся; внизу сайдбара видна пометка «превью».
- `released` — версия подготовлена к выпуску; в интерфейсе остаётся только номер.

Номер относится к выпуску, а не к каждому промежуточному коммиту. Точный проверенный коммит указываем в PR и результатах Actions. Значение в файле само по себе не подтверждает прохождение проверок или публикацию.

## Как выпускать

1. Перед приёмкой выбрать дату и следующий свободный номер. Если выпуск переносится на другой день, поменять дату. В `app-version.js` установить номер и `stage: "released"`, обновить `?v=` этого файла в `index.html`.
2. Закоммитить финальные изменения и по явной команде выполнить серверную приёмку именно этой версии. На Mac проверки не запускать. Любая последующая правка создаёт новый SHA, для которого нужна приёмка.
3. После одобренного PR и слияния создать тег `v` + номер из файла на выпускаемом коммите, оформить GitHub Release с русским описанием. Старые теги не переносить. Проверку опубликованной версии запускать отдельно по разрешению.

Создание файла версии ничего не публикует автоматически. Установка пакетов, сборка и сервис определения версии не нужны. Параметры `?v=` у остальных JS/CSS продолжают обновляться при изменении соответствующих файлов — это ключи кэша, не версии приложения.

## Дата снимка — отдельно

`SEKTA_CURRENT_GRID_META.asOf` в [`data/current-grid.js`](../data/current-grid.js) задаёт дату сохранённой сетки Instagram. Из неё формируются дата в сайдбаре и пояснения раздела сетки. При обновлении набора кадров меняем данные и дату вместе.

В текущих данных — снимок за **25 августа 2026**, обновлённый коммитом `971da27` (`Refresh current Instagram grid`). Прежняя подпись «13 августа» осталась от более раннего набора и не соответствовала подключённым кадрам.

Медиатека имеет собственный `generatedAt` — 3 сентября 2026. Ни дата каталога, ни версия приложения не делают Instagram-снимок свежим. Подключения к live-ленте нет, поэтому подпись — «Снимок Instagram», без обещания актуальности.
