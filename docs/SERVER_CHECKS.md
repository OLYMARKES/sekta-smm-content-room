# Серверная приёмка

Проверки запускаются только по явной команде пользователя. Mac не используется для тестов, браузеров, сборок или установки проверочных зависимостей.

## Как устроено

Workflow [Server acceptance](../.github/workflows/server-checks.yml) использует одноразовые runner GitHub Actions на Ubuntu. Сначала выполняются 23 регрессионных теста с подменой изображений, хранилища и транспорта. Затем Chromium и WebKit проверяют приложение с настоящим каталогом на отдельном HTTP-origin с путём `/sekta-smm-content-room/`.

Браузерные сценарии охватывают навигацию и типографику, черновики и JSON, конфликт вкладок, отказ хранилища, пустую песочницу, имена и `top`, размер PNG, сохранность начатой сцены, CORS, отмену перехода к превью, мобильную ширину и клавиатуру. Локальный сервис заменяется тестовым ответом; реальных POST и правок рабочих данных нет. Google Fonts в изолированном прогоне отключены, поэтому он не подтверждает доступность всех внешних шрифтов.

Проверочные пакеты устанавливаются в временный каталог runner. Приложение остаётся статическим и не получает npm-зависимостей или сборки. Скриншоты и результаты сохраняются как артефакты Actions на 3 дня, не в Git.

Для текущей ветки `docs/content-room-review` согласованы прогоны после push. После слияния ветка удаляется; дальнейшие запуски — вручную через Actions → Server acceptance → Run workflow и только после разрешения.

## После публикации

Ручной запуск с параметром `check_live: true` повторяет приёмку и дополнительно читает опубликованный сайт. SHA-256 HTML, CSS и изменённых скриптов должен совпасть с checkout запуска. Затем оба браузера открывают опубликованную страницу и проверяют запуск конструктора. Запись в локальный сервис заблокирована; рабочие черновики пользователей не затрагиваются.

Зелёный результат относится к конкретному SHA. Он не подтверждает права публикации медиа, доступность всех оригиналов, работу отсутствующего сервиса или полное визуальное совпадение всех гарнитур. Эти ограничения остаются в [разборе проекта](PROJECT_REVIEW.md).
