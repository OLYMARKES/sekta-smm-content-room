# Сохранение имён, отметок и сетки

В текущей ветке приложение работает только локально: правки остаются в браузере, автоматической отправки на localhost больше нет. Общий API не настроен. Первая версия хранения вошла в [PR #1](https://github.com/OLYMARKES/sekta-smm-content-room/pull/1); новые изменения требуют отдельной [серверной приёмки](SERVER_CHECKS.md).

## Имена и отметки

Правка сначала записывается в хранилище, затем применяется в интерфейсе. При ошибке имена остаются в форме, а звезда не переключается. Ключ `sekta-media-people-overrides-v1` и старые поля `pending` / `pendingFields` сохранены без миграции.

Очередь транспорта в `media-overrides.js` остаётся совместимой со старым форматом и покрывается модульными тестами, но приложение её не запускает. Наличие `pending: true` теперь не обещает будущую фоновую отправку. Для командной синхронизации нужны отдельные решения об авторизации, доступе, версиях записей и конфликтах.

## Будущая сетка

`workspace-safety.js` читает прежний ключ `sekta-sandbox`, проверяет структуру до девяти записей и допустимые ссылки на изображения. Пустая сетка остаётся пустой после перезагрузки. Повреждённая копия не перезаписывается автоматически.

Добавление, удаление, перемещение и сброс сначала сохраняются. При отказе хранилища интерфейс оставляет прежнюю сетку и показывает ошибку. Конструктор сообщает об успешном добавлении только после подтверждения песочницы. Если сохранить нельзя, скачайте новую обложку отдельно.

## Границы

Сравнение значения до записи замечает уже произошедшую запись другой вкладки, но не является атомарной блокировкой. Строго одновременные записи по-прежнему требуют другой модели хранения. При конфликте перезагрузите страницу; для обложки сначала экспортируйте JSON.

Локальные правки имеют приоритет над каталогом и могут скрывать более поздние редакционные изменения. Браузеры, компьютеры и разные адреса сайта не делят одно хранилище. Очистка данных сайта удаляет локальные копии. В боковом меню добавлен [экспорт сохранённых данных](LOCAL_BACKUP.md), включая сетку и имена; автоматического восстановления пока нет. Перед скачиванием сохраните имена из открытой формы.

## Приёмка

На сервере проверить:

1. Имена и `top` сохраняются после перезагрузки; POST к localhost нет.
2. Отказ записи не меняет звезду и не удаляет введённые имена.
3. Неудачная запись сетки не меняет сохранённую и видимую версии.
4. Пустая сетка восстанавливается; повреждённая остаётся нетронутой.
5. Чужая уже замеченная запись не затирается.
6. Полная сетка не приводит к ложному сообщению об успешном добавлении.

Сценарии подготовлены. Результаты серверной приёмки конкретных SHA — в [PR #2](https://github.com/OLYMARKES/sekta-smm-content-room/pull/2).
